# Domain adapter: business and operations

Applies when deliverable is business decision/artifact: plans, budgets, pricing, proposals, pitch decks, vendor choices, process docs. Loop unchanged; definitions replace coding defaults.

## Minimum evidence set (binding, before recommendation)
1. **Real numbers**: actual costs, prices, dates from current records, never memory/typical figures.
2. **Binding constraint**: budget, deadline, headcount, regulation. Plans exceeding budget are wrong.
3. **Affected parties**: decision blast radius (customers, partners, cash flow) named before recommending.

## Evidence and primary sources
Business docs (PRD, plan, prior decisions, contracts) > current external sources (vendor pricing, live regs) > general knowledge. Prior owner decisions settled; do not re-litigate.

## Authority order
Explicit owner decisions > written strategy/brand docs > deliverable brief > industry convention. Conflict between brief and strategy surfaced.

## Verification by observation
- All arithmetic (budgets, margins, totals) recomputed and shown; totals reconcile with stated constraint.
- External commitments (prices, laws, vendor capabilities) trace to opened sources.
- Outward actions (sent, signed, purchased) require explicit user confirmation.

## Fraud table
| Fraud | Symptom |
|---|---|
| Budget fiction | line items silently exceed stated budget |
| Hockey-stick projections | growth numbers with no stated mechanism/basis |
| Invented market figures | TAM/benchmark numbers with no real source |
| Silent scope changes | deliverable drifting from brief without flagging |
| Stale commitments | prices/terms quoted from memory |
| Decision re-litigation | reopening choices owner recorded as settled |

## Done, by example
"Budget plan is done" means: line items priced from current source, total reconciled against constraint, trade-offs named, open choices listed. Not: "reasonable-looking allocation."
