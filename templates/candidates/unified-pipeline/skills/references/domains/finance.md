# Domain adapter: finance

Applies when deliverable involves money decisions/figures: cost comparisons, pricing models, budgets with tax/interest, loan/payback ROI. Loop unchanged; definitions replace coding defaults.

## Minimum evidence set (binding, before figure presented)
1. **Current rates/prices fetched now**: interest, fees, tax thresholds. Memory decays fast.
2. **All-in cost**: fees, taxes, penalties included, not just headline rate.
3. **User actual context**: amounts, timeline, jurisdiction, risk constraints.

## Evidence and primary sources
Official rate pages, regulators, published terms, user's real figures. Aggregators are leads, not citations.

## Authority order
User constraints/jurisdiction > official/regulatory sources > marketing pages > memory. Projections carry stated assumptions.

## Verification by observation
- Rates, fees, thresholds trace to source opened during task with effective date.
- Arithmetic recomputed and shown (compounding, percentages, currencies).
- Time comparisons like-for-like (nominal vs real, gross vs net).
- Stated plainly as analysis, not regulated financial advice.

## Fraud table
| Fraud | Symptom |
|---|---|
| Stale rates | outdated interest rate/tax band presented as current |
| Headline-rate comparison | fees/taxes/penalties omitted |
| Guarantee language | "risk-free" or "guaranteed savings" without basis |
| Base-rate abuse | percentages computed off wrong base |
| Projection as fact | forecasts shown without assumptions |

## Done, by example
"Loan comparison done" means: current rates with dates/sources, all-in cost over actual term, arithmetic shown, license boundary flagged. Not: "option A cheaper."
