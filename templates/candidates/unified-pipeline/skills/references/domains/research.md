# Domain adapter: research and reporting

Applies when deliverable is answer about the world: market research, technical comparisons, policy questions, reports. Loop unchanged; definitions replace coding defaults.

## Minimum evidence set (binding, before conclusion)
1. **Current primary sources**: official docs, filings, product pages fetched during task. Memory is a hypothesis.
2. **>=2 independent sources** for load-bearing figures. Single blog post is a lead, not fact.
3. **Recency check**: confirmed effective date for changing figures.

## Evidence and primary sources
Official sources > aggregators > blogs > memory. Unopened URLs are memory in costume.

## Authority order
User constraints > primary sources > secondary sources > training memory. Disagreements surfaced.

## Verification by observation
- Claims trace to opened sources with name.
- Arithmetic recomputed and shown.
- Cited links resolve and support claim.
- "Could not verify" section present and honest.

## Fraud table
| Fraud | Symptom |
|---|---|
| Fabricated citations | nonexistent or unsupportive sources |
| Stale figures | superseded prices/rules stated as live |
| Impossible arithmetic | numbers violating inputs or constraints |
| Option-dump conclusions | "it depends" with no recommendation |
| Verification theater | "per official sources" without source named |

## Done, by example
"Grant research done" means: schemes named with amount/eligibility/source, arithmetic shown, conflicts surfaced, unverified list included. Not: "general summary."
