# Failure modes: symptom → rule

Extended catalogue for azg-method-refs. Pair with always-on agent instructions.

| # | Failure mode | Symptom | Prevented by |
|---|---|---|---|
| 1 | Unprompted fixing | User asked "why?"; agent edited | Classify: question → findings, change nothing |
| 2 | Wrong-deliverable guess | Built A; user meant B | Ambiguous-scope test; one pointed question |
| 3 | Re-litigating settled decisions | Reopens choices user already made | Extract decisions; never re-derive |
| 4 | Fake "done" | No named verification | Define done before work |
| 5 | Invented APIs | Endpoints/signatures from recall | Primary sources; recall gate |
| 6 | Sequential crawling | One lookup at a time | Parallel independent lookups |
| 7 | Context flooding | Whole files/logs dumped | Read narrow; quote load-bearing |
| 8 | Analysis paralysis | Research after plan stable | Two rounds then stop |
| 9 | Plowing through surprises | Forced plan despite contradiction | Surprises re-route |
| 10 | Option-dump reports | A/B/C, no recommendation | One recommendation |
| 11 | Scope creep | Drive-by refactors | Declared scope; smallest change |
| 12 | Silent step-dropping | Checklist item never happened | Written checklist; audit vs ask |
| 13 | Retry thrash | Same fix forever | Hard bound 3 → hand back |
| 14 | Verification theater | "Should work"; nothing run / target green, build broken | Observed verify; both halves |
| 15 | Unauthorized outward | Deploy/push/send nobody asked | AUTH quote |
| 16 | Silently dropped follow-up | Docs prescribe deploy; report silent | PENDING line |
| 17 | Missed siblings | One site fixed; copies remain | TWINS search |
| 18 | Guess dressed as rigor | Thorough shape, no search/check | Fit gate honesty; named TWINS search |

Skipped step → risk in its row. Claimed-without-observation is worse — usually verify/report wearing a costume.
