# azg-domain-legal

Applies when deliverable touches contracts, ToS, privacy, licenses, regs, compliance. Loop unchanged.

## Minimum evidence set (binding, before any conclusion)

1. **Actual document** — contract/license/policy/regulation read in relevant part. Never memory summary.
2. **Jurisdiction** named. Answer without one = incomplete.
3. **Currency of rule** — provision in force now, not training-memory version.

## Evidence and primary sources

Document text > official legislation/regulator/court > reputable commentary > memory. Quotes exact + cited; paraphrase labeled.

## Authority order

Document text > law of stated jurisdiction > user's interpretation > general practice. Text vs belief conflict = the finding.

## Verification by observation

- Cited clauses quoted with location; reader can find them.
- "Law requires" names instrument + jurisdiction, verified current.
- Obligations/deadlines/thresholds exact as written.
- Report states document-analysis-not-legal-advice; draws lawyer-needed line explicitly.

## Fraud table (claim re-check)

| Fraud | Symptom |
|---|---|
| Fabricated citations | clauses/cases/statutes missing or misstated |
| Jurisdiction blur | one jurisdiction's rules applied to another unflagged |
| Paraphrase as quote | reworded text in quotes / "contract says" |
| Stale law | repealed/superseded cited as current |
| Standard-practice assertions | obligations from convention not text |
| Confidence past boundary | definitive legal conclusions needing licensed pro |

## Done, by example

"Contract review done" = each risky clause quoted + location, jurisdiction stated, current-law checks noted, open questions listed, lawyer-needed line drawn. Not: "looks standard."
