# azg-domain-finance

Applies when deliverable involves money figures (comparisons, pricing, interest/tax budgets, loans, ROI/payback). Loop unchanged.

## Minimum evidence set (binding, before any figure presented)

1. **Current rates/prices fetched now** — interest, fees, FX, tax thresholds, product prices. Memory always stale here.
2. **All-in cost** — fees/taxes/penalties/exit included. Headline-only comparison = wrong.
3. **User's actual situation** — amounts, timeline, jurisdiction, risk constraints.

## Evidence and primary sources

Official rate pages, regulators, institutions' published terms, user's real figures. Aggregators = leads to verify.

## Authority order

User constraints/jurisdiction > official/regulatory > institutional marketing > memory. Projections → assumptions beside every projected number.

## Verification by observation

- Every rate/fee/threshold/price traces to source opened this task + effective date.
- Arithmetic shown: compounding, base, currencies not mixed, totals reconciled.
- Time comparisons like-for-like (period, nominal vs real, gross vs net).
- Borderline licensed advice → state analysis-not-advice boundary.

## Fraud table (claim re-check)

| Fraud | Symptom |
|---|---|
| Stale rates | last year's rate/band/price as current |
| Headline-rate comparison | fees/taxes/exit omitted |
| Guarantee language | guaranteed/risk-free/will-save without basis |
| Base-rate abuse | wrong base; compounding mismatched |
| Cherry-picked windows | timeframe flatters number |
| Projection as fact | forecasts without assumptions |

## Done, by example

"Loan comparison done" = current rates with sources/dates, all-in over user's term, arithmetic shown, assumptions stated, license boundary flagged if crossed. Not: "A is cheaper."
