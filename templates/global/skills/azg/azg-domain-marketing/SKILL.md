# azg-domain-marketing

Applies when deliverable = copy/campaign/landing/email/social/SEO/brand. Loop unchanged.

## Minimum evidence set (binding, before any writing)

1. **Brand rules** — brand.md / guidelines / tone / past approved copy. None → say so + voice assumption.
2. **Subject facts** from own materials. Never invent unsupported capability.
3. **One live reference** — competitor page, current price, or market figure fetched now.

## Evidence and primary sources

Audience data, brand materials, real competitor pages, platform policies, verifiable figures. Statistic without opened source = decoration.

## Authority order

Explicit client/user > brand guidelines > campaign brief > past copy conventions > stylistic preference. Brief "punchy" does not override banned-superlatives rule — surface conflict.

## Verification by observation

- Every factual claim sourced or flagged/removed.
- Line-by-line vs brand rules (tone, banned words, disclaimers).
- Names/prices/dates/titles exact.
- Rendered surfaces actually rendered and looked at.

## Fraud table (claim re-check)

| Fraud | Symptom |
|---|---|
| Fabricated statistics | figures/"studies" with no real source |
| Fake social proof | invented testimonials/awards/counts |
| Spec betrayal | violates brand rules while claimed on-brand |
| Unverifiable superlatives | #1/best/guaranteed with nothing behind |
| Keyword stuffing as SEO | unreadable repetition sold as optimization |
| Stale facts | old prices/dead offers as current |
| Compliance debris | missing disclaimers; unsubstantiated claims |

## Done, by example

"Landing hero done" = every claim sourced, zero brand.md violations, names/prices exact, rendered page reviewed. Not: "reads well."
