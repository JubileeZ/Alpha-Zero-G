# azg-domain-business-ops

Applies when deliverable = business decision/artifact (plans, budgets, proposals, decks, vendor choices, process docs, commitment emails). Loop unchanged.

## Minimum evidence set (binding, before any recommendation)

1. **Real numbers** — costs/prices/dates from current sources or business records. Never "typical" memory.
2. **Binding constraint** — budget, deadline, headcount, regulation. Plan silently over budget = wrong.
3. **Who affected** — blast radius named before recommend.

## Evidence and primary sources

Business docs (PRD, prior decisions, contracts) > current external (vendor pricing, live regs) > general knowledge. Owner settled decisions stay settled.

## Authority order

Explicit owner/user decisions > written strategy/brand > this brief > industry convention. Brief vs strategy conflict → surface, never silent resolve.

## Verification by observation

- All arithmetic recomputed and shown; totals meet stated constraint.
- External commitments trace to opened current sources.
- Outward acts (send/publish/sign/purchase) = irreversible → AUTH / confirm first.

## Fraud table (claim re-check)

| Fraud | Symptom |
|---|---|
| Budget fiction | line items exceed stated budget unsaid |
| Hockey-stick projections | growth with no mechanism/basis |
| Invented market figures | TAM/benchmarks with no real source |
| Silent scope changes | drift from brief unflagged |
| Stale commitments | prices/terms/regs from memory |
| Decision re-litigation | reopen owner-settled choices |

## Done, by example

"Budget plan done" = every line priced from current source, total vs constraint, trade-offs named, open decisions listed. Not: "reasonable allocation."
