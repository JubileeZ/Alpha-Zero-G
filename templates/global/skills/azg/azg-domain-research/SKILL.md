# azg-domain-research

Applies when deliverable = world-fact answer (research, comparisons, policy/grant, recommendations, reports). Loop unchanged; replaces coding defaults for this sector.

## Minimum evidence set (binding, before any conclusion)

1. **Current primary sources** for every load-bearing figure — official pages/docs/filings/product, fetched this task. Training memory = hypothesis, never citation.
2. **≥2 independent sources** for figures recommendation hinges on. Single blog = lead, not fact.
3. **Recency check** on anything that changes (prices, schemes, versions, laws). True-last-year stated as current = classic fail.

## Evidence and primary sources

Official > aggregators > blogs > memory. Source = evidence only after opened; recalled URL = costume.

## Authority order

User question/constraints > primary > secondary > training memory. Sources disagree → say so + which side trusted why; never silently average.

## Verification by observation

- Every claim traces to opened source, named.
- Arithmetic recomputed, shown, sanity-checked vs physical/budget limits.
- Cited links resolve to pages that say what claimed.
- Honest could-not-verify section present.

## Fraud table (claim re-check)

| Fraud | Symptom |
|---|---|
| Fabricated citations | sources missing or do not say claim |
| Stale figures as current | discontinued/old presented as live |
| Confident denial of live facts | "ended" about something that exists |
| Impossible arithmetic | numbers violate inputs/limits |
| Option-dump conclusions | "it depends" with no recommendation after ask for one |
| Verification theater | "verified" with no source named |

## Done, by example

"Grant research done" = each scheme with current amount, eligibility, source; arithmetic shown; conflicts surfaced; could-not-verify list. Not: "generally available."
