# Domain adapter: research and reporting

Applies when the deliverable answers a question about the world: research notes, comparisons, policy/grant questions, recommendations, reports. Loop unchanged; these nouns replace coding defaults.

## Minimum evidence set (binding, before any conclusion)

1. **Current primary sources** for every load-bearing figure — opened this task. Cite only what you opened; training memory is hypothesis until fetched.
2. **At least two independent sources** for any figure the recommendation hinges on.
3. **Recency check** for anything that changes (prices, versions, laws, schemes).

## Evidence and authority

Official > aggregators > blogs > memory. A recalled URL not fetched is memory in costume.

Authority: user question/constraints > primary sources > secondary > training memory. When sources disagree, say so and which side you trust.

## Verification by observation

- Every claim traces to a named source you opened.
- Arithmetic recomputed, shown, sanity-checked.
- Cited links resolve to what you claim.
- Honest could-not-verify section (absence is a red flag).

## Fraud table (Prove)

Apply every row to the draft conclusion before Done:

| Fraud | Symptom |
|---|---|
| Fabricated citations | missing/wrong sources |
| Stale figures as current | old prices/rules stated live |
| Confident false denial | "ended" about something that exists |
| Impossible arithmetic | numbers vs stated inputs |
| Option-dump | "it depends" with no recommendation when asked |
| Verification theater | "per official sources" with no source named |
| Narrative as evidence | Method prose for levers not fetched/simulated |

## Done

Every load-bearing figure named with amount/eligibility (as applicable), source opened this task, arithmetic shown when used, conflicts surfaced, could-not-verify list present. Exit only when each fraud row is applied (or N/A).
